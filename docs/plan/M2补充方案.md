## 2）新增 `storage/` 抽象，把原始文件先保存下来

### 要新增的文件
- `src/main/java/com/agenticrag/rag/storage/StorageClient.java`
- `src/main/java/com/agenticrag/rag/storage/LocalFileStorageClient.java`

### 为什么必须先做
因为异步化以后，不能还把 `MultipartFile.getInputStream()` 传给后台线程慢慢处理。  
正确做法是：

1. Controller 收到文件
2. 先保存到本地 `data/files/`
3. 数据库插入 `PENDING`
4. 后台线程再从文件路径读取并处理

### 接口建议
```java
public interface StorageClient {
    String save(String filename, InputStream in) throws Exception;
    InputStream get(String filePath) throws Exception;
    void delete(String filePath) throws Exception;
}
```

### 本地实现建议
- 保存目录：`rag.data-dir/files`
- 文件名防冲突：可以用 `UUID + 原文件名后缀`
- 返回相对路径或绝对路径都可以，但 `documents.file_path` 里要能稳定找回

## 6）实现 PDF 页眉页脚清洗

### 要改的文件
- [PdfDocumentParser.java](file:///Users/miaobao/agent-projects/agentic-rag/src/main/java/com/agenticrag/rag/ingest/PdfDocumentParser.java)

### 现在的问题
当前实现是整篇直接抽文本，没法识别“跨页重复行”。

### 新做法
按页提取：
- 第 1 页文本
- 第 2 页文本
- ...
- 第 N 页文本

然后做跨页重复行去重：
- 把每页按行拆开
- 统计哪些行在多页中重复出现
- 对重复出现次数超过阈值的行，判断为页眉/页脚候选
- 从最终文本中移除

### 工程上建议
先做一个简单版本就够了：
- 只处理“完全重复行”
- 忽略空行和很短的行
- 重复出现在 `>= 2` 或 `>= 3` 页就删掉
