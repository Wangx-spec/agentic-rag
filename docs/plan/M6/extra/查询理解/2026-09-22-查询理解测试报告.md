# 查询理解前置测试报告

## 1. 范围

本报告覆盖 AGENT ReAct 循环前的查询理解服务、配置开关、检索引导注入、意图回填及故障开放行为。

## 2. 自动化测试

| 测试项 | 结果 |
|---|---|
| `QueryUnderstandingServiceTest` | 7/7 通过 |
| `ChatServiceTest` | 5/5 通过 |
| 全量 `./mvnw test` | 143/143 通过 |
| 主代码 `./mvnw compile -q` | 通过 |

覆盖路径：

- KB_QA 正常理解：意图、置信度、规范查询正确解析
- MULTI_TASK：子查询列表正确解析
- Markdown JSON 代码块容错
- 非法 JSON、未知意图、低置信度、LLM 异常均返回 `Optional.empty()`
- 开关关闭时不调用 LLM
- ChatService 将规范查询注入 system 消息，并保留原始问题和 routedIntent
- 既有 RAG、AUTO、工具及 Agent 测试无回归

## 3. 代码验收

- `QueryUnderstanding` 四字段 record 已实现。
- `QueryUnderstandingService` 使用一次 LLM 调用完成意图、规范查询和多任务拆解。
- 五类意图定义与现有 `IntentClassifier` 保持一致。
- `RAG_AGENT_QUERY_UNDERSTANDING_ENABLED` 默认开启，关闭后 fail-open 回退原 Agent 行为。
- 查询理解失败不向用户抛错，不阻断 Agent ReAct 循环。
- 原始用户问题仍通过 `AgentContext.originalQuery` 保留。

## 4. 外部评测状态

r09 原题和 r09v1 去术语化变体需要真实 LLM、Embedding、向量库和评测判分服务，当前未在本地自动测试中执行，因此以下指标待回填：

- r09 原题 64 题：与 r07d 的 recall、completeness、correctness、invalid extra 对比
- r09v1 变体 64 题：与 r09 原题 recall 差距是否小于 15pp
- answers 是否零 `<tool_call>` 泄漏

## 5. 结论

代码功能和本地自动化验收通过；外部评测属于部署环境验收，需要按部署说明执行后回填本目录 checklist。
