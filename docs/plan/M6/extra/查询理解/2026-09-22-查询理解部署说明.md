# 查询理解前置部署说明

## 1. 前置条件

- Java 17
- Maven Wrapper（项目自带 `./mvnw`）
- PostgreSQL、Redis、Qdrant（按现有项目配置启动）
- 可访问 OpenAI 兼容接口的 `LLM_API_KEY`
- 已完成知识库导入，向量索引和 BM25 索引可用

## 2. 配置

查询理解默认开启：

```bash
export RAG_AGENT_QUERY_UNDERSTANDING_ENABLED=true
```

关闭查询理解并回退到 r07d 口径：

```bash
export RAG_AGENT_QUERY_UNDERSTANDING_ENABLED=false
```

常用基础配置：

```bash
export LLM_API_KEY='从密钥管理系统注入'
export LLM_BASE_URL='https://api.siliconflow.cn/v1'
export LLM_CHAT_MODEL='zai-org/GLM-5.3'
export RAG_RETRIEVAL_MODE=hybrid
export RAG_RETRIEVAL_REWRITER_ENABLED=true
export RAG_RETRIEVAL_HYDE_ENABLED=true
export RAG_RETRIEVAL_RERANK_ENABLED=true
export RAG_AGENT_CITATION_TOP_N=5
export RAG_AGENT_DOCUMENT_TOOLS_ENABLED=false
```

API Key 只通过环境变量或外部密钥管理系统注入，不写入仓库文件。

## 3. 编译与启动

```bash
./mvnw compile
./mvnw spring-boot:run
```

启动后使用聊天接口选择 `AGENT` 模式。查询理解成功时，应用日志会输出意图、规范查询和子查询数量；失败时自动跳过，不影响主流程。

## 4. 本地验证

```bash
./mvnw test -Dtest=QueryUnderstandingServiceTest,ChatServiceTest
./mvnw test
```

预期结果：新增测试 12 项通过，全量测试 143 项通过。

## 5. r09 原题评测

在项目根目录执行：

```bash
EVAL_ERAG_CHAT_MODE=agent \
RAG_AGENT_DOCUMENT_TOOLS_ENABLED=false \
ROUNDS_DIR=eval-answers/rounds-era2 \
./scripts/run-erag-round.sh r09 hybrid 1 1 1 \
> eval-answers/rounds-era2/r09-run.log 2>&1

ROUNDS_DIR=eval-answers/rounds-era2 \
./scripts/run-erag-judge.sh r09 \
> eval-answers/rounds-era2/r09-judge.log 2>&1
```

验收：

```bash
wc -l eval-answers/rounds-era2/r09.jsonl
grep -c '<tool_call' eval-answers/rounds-era2/r09.jsonl
```

应有 64 行答案，泄漏计数为 0。随后从判分结果提取四指标并回填 checklist。

## 6. r09v1 变体评测

```bash
EVAL_ERAG_CHAT_MODE=agent \
RAG_AGENT_DOCUMENT_TOOLS_ENABLED=false \
EVAL_ERAG_QUESTIONS=eval-answers/rounds-era2/v1-dejargon.jsonl \
ROUNDS_DIR=eval-answers/rounds-era2 \
./scripts/run-erag-round.sh r09v1 hybrid 1 1 1 \
> eval-answers/rounds-era2/r09v1-run.log 2>&1

ROUNDS_DIR=eval-answers/rounds-era2 \
./scripts/run-erag-judge.sh r09v1 \
> eval-answers/rounds-era2/r09v1-judge.log 2>&1
```

将 r09v1 recall 与 r09 原题 recall 对比，确认差距小于 15pp；若原题 correctness 相对 r07d 回退超过 3pp，应将开关默认关闭并保留为可配置实验项。
