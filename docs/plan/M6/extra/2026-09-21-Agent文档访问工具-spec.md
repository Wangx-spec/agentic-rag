# Agent 文档访问工具（get_document / list_documents）+ r08b 消融 Spec

> 日期：2026-09-21 ｜ 阶段：准确率轨收尾（M6 后续） ｜ 前置：r07d 为当前最佳配置

## 背景

- M6 已收官，最佳成绩 r07d（AGENT + rerank + 引用裁剪 top5）：Document Recall 68.28 / Correctness 43.75 / 28 题满分 / Invalid Extra 3.27，零终答泄漏。
- 当前 AgentLoop 的 ReAct 工具箱里只有一个检索类工具（search_knowledge_base），Agent 拿到 chunk 后无法回溯原文全文、也无法浏览知识库里有哪些文档。工具数量单一，既是能力短板，也是面试叙事短板。
- 已勘察代码：文档仓储已有「按 ID 查文档」「查全部文档」「按文档 ID 查 chunk」三个方法，两个新工具底层数据访问零新增。语料约 5187 篇、平均 25 chunk/篇，全文返回必须截断。
- 工具集变化会改变 Agent 行为，必须在配置冻结、定版复测之前完成这次补强，并用一轮消融验证净贡献。

## 目标

- 为 Agent 新增两个文档访问工具：按 ID 取文档内容（截断+提示）、限量列出文档（ID/标题/摘要/chunk 数）。
- 跑一轮 r08b 消融：r07d 配置不变、唯一变量是多注册这两个工具，内置 64 题原题，与 r07d 对比得出净贡献。
- 全程 fail-open：工具异常不中断 Agent 主流程。

## 功能需求

- **F1: 文档读取工具（get_document）**
  - 输入：文档 ID。
  - 行为：返回该文档的正文内容，附元信息（文档 ID、标题、总字符数、chunk 数）。
  - 超长处理：正文超过上限（默认约 8000 字符，可配置）时截断，并在结果中明确标注「已截断，完整内容共 X 字符」，让 Agent 知道看到的是部分内容。
  - 异常处理：文档 ID 不存在或参数缺失/非法时，返回明确的提示文本，不抛错中断。

- **F2: 文档列表工具（list_documents）**
  - 输入：可选的数量上限（默认值如 20，可配置）。
  - 行为：返回限量文档列表，每篇仅含：文档 ID、标题、首段摘要、chunk 数；只列出已入库完成的文档。
  - 用途定位：让 Agent 浏览知识库概况、拿到文档 ID 后再调 get_document 深读。

- **F3: 工具注册与发现**
  - 两个工具接入现有工具框架（与 search_knowledge_base 同一套接口与注册机制），AGENT 模式下可被 AgentLoop 自动发现和调用，不改动 AgentLoop 与对话主流程代码。
  - 工具描述文本写清楚「什么时候该用我」，引导模型正确选择工具。

- **F4: 故障开放（fail-open）**
  - 两个工具内部任何异常（仓储错误、空结果、参数非法等）都转化为文本提示返回给 Agent，不抛出、不中断 ReAct 主循环。

- **F5: r08b 消融评测**
  - 基线：r07d 配置（AGENT 模式 + Query 改写 + HyDE + rerank + citationTopN=5），唯一变量是多注册这两个工具。
  - 跑内置 64 题原题一轮，输出与 r07d 同口径的四指标（Document Recall / Completeness / Correctness / Invalid Extra），对比得出净贡献并归档。

## 非功能需求

- N1: 截断上限、列表默认数量可通过配置调整，无需改代码。
- N2: 工具单次执行在本地数据量（5187 篇）下秒级返回，不引入新的外部服务调用。
- N3: 与现有工具风格一致：中文描述、中文结果渲染、文本块结构清晰，便于模型阅读。
- N4: 单元测试覆盖正常路径与异常路径（不存在 ID、非法参数、截断、限量）。

## 不做的事

- 不做查询理解前置改造、不做 rerank 阈值过滤（属于另一批准确率改动，另行评估）。
- 不做工具调用权限/配额管理、不做多知识库隔离（M7/M8 范畴，已决定跳过）。
- 不做 MCP 工具接入（叙事另行规划）。
- 不改 AgentLoop、ChatService、评测脚本逻辑；不动 citationTopN 等已冻结配置。
- 不为这两个工具单独设计新指标，复用现有四指标。

## 验收标准

- AC1（对 F1）：用存在的文档 ID 调用 get_document，返回正文+元信息；正文超长时结果被截断且带「已截断，完整内容共 X 字符」标注。
- AC2（对 F1）：用不存在的文档 ID、缺失/非法参数调用 get_document，返回明确提示文本，进程不异常。
- AC3（对 F2）：调用 list_documents 返回不超过上限的列表，每项含 ID/标题/摘要/chunk 数，且不含未入库完成的文档。
- AC4（对 F3）：启动应用后 AGENT 模式的可用工具列表中出现 get_document 与 list_documents（日志可见注册记录）。
- AC5（对 F4）：对两个工具分别制造异常输入，Agent 主循环继续运行，不出现未捕获异常。
- AC6（对 F5）：r08b 跑完 64 题并判分，四指标与 r07d 同口径对比表归档到 checklist 文档；作答与判分日志保留在 rounds-era2 目录。
