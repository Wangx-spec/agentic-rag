- [ ] 异步写回不阻塞响应（验证：SSE done 事件先于摘要/提取完成（应用日志时间戳对比）；关停后端存储时问答仍正常返回）

## 端到端场景

- [ ] **场景 1 · 持久化**（AC1）：jdbc 模式下多轮对话 → 重启服务 → 同 sessionId 继续提问 → 回答正确引用重启前的上下文
- [ ] **场景 2 · 偏好跨会话**（AC3）：会话 A 中明确表达偏好（「以后回答都用英文」）→ 触发一轮批量提取（对话满 5 轮或手动等待）→ 新开会话 B 首问 → system prompt 注入该偏好（调试日志或回答风格为英文验证）
- [ ] **场景 3 · 结论跨会话检索**（AC4）：会话 A 中给出明确结论（「记住：项目截止日期是 10 月 15 日」）→ 提取写入长期记忆 → 新会话 B 提问「截止日期是什么时候」→ 回答命中该日期；Agent 模式下问「回忆一下之前说过的截止日期」→ LLM 自主调用 search_memory 取回（AC5）
- [ ] **场景 4 · 窗口受控**（AC2）：单会话持续 30+ 轮（可脚本灌入）→ 调试端点或日志观察发送给 LLM 的消息数 ≤ keepTurns×2+2 且首条为 [历史摘要] system 消息
- [ ] **场景 5 · 成本受控**（AC6）：连续 10 轮对话 → 日志统计提取类 LLM 调用 ≤ 2 次、摘要调用按半窗口重叠规则触发
- [ ] **场景 6 · 降级**（AC7）：停掉 Qdrant（或注入读超时）后提问 → 问答正常返回（无长期记忆注入、无报错）；恢复后自动恢复完整功能
- [ ] **场景 7 · 管理闭环**（AC8）：curl 写入/查看/清除实体记忆与长期记忆四端点往返 → 清除后相关对话检索不再命中
- [ ] **场景 8 · M8 兼容预演**：userId=1 与 userId=2 各自对话、表达不同偏好 → 互不可见对方记忆（数据隔离预验证，M8 落地后只需接入真实登录态）
